# 代码规范

> 适用于本仓库全部前后端代码；AI 生成的代码同样必须遵守。分层与流程见 [开发流程.md](开发流程.md)。

## 1. 通用

- **注释**：必要的方法与页面加**中文注释**，说明业务含义（为什么），不复述代码（做了什么）。公开工具函数/复杂逻辑必注，自明代码不注。
- **命名**：Python 用 snake_case（类 PascalCase，私有成员 `_` 前缀）；TS/JS 用 camelCase（类/组件/类型 PascalCase，常量 UPPER_SNAKE）；文件名全小写（Python snake_case，Vue 组件 PascalCase，页面路由文件小写）。
- **文档**：重要设计决策写入对应 doc 文档，不在代码注释里写长篇设计。

## 2. Python 3.13（后端）

```python
# ✅ 新类型语法(强制)
def search(query: str, project_ids: list[str] | None = None) -> dict[str, Any]: ...
async def load(name: str) -> Config | None: ...

# ❌ 禁用旧式 typing 写法
from typing import Optional, Union, List, Dict   # 禁止
```

- **异步**：I/O 全异步（async/await）；CPU 密集或阻塞库放任务队列，不在请求协程内直跑。
- **分层约束**：controller 不写业务；service 不 import controller；**每个业务线模块保持完整的 controller/service/dao/do/dependencies 五件套**；非业务算法（纯计算/格式转换/无业务状态的工具）放模块 `utils/`，不放 service。
- **跨模块协作**：模块间禁止互引 controller/dao/do 等内部文件；**复杂业务依靠 service 之间调用实现**（A 模块 service import B 模块 service 的对外入口）；通用能力下沉 `common/`。
- **重依赖惰性加载**：非启动必需的重库（langchain 系/babylon 级别的重物）在函数内 import，保持启动轻快。
- **pydantic v2 / SQLModel**：请求响应体用 Pydantic 模型；表模型 `table=True`；`model_config = ConfigDict(extra="forbid")` 用于动态配置 schema（收严输入），存量兼容场景可用 `extra="ignore"`。
- **依赖约束**：禁引入 torch / transformers / paddle 等单体 500MB+ 大库；模型能力一律走外部服务（在线 API）接入；新增依赖先 grep 全库确认无既有能力可复用。
- **配置**：引导级（db_rel/server/admin）进 config.yaml；业务可热更配置进动态配置中心（sys_config）；禁止硬编码密钥，密钥走 `_secret_fields` 打码机制。

## 3. Vue3 + TypeScript（前端）

- **组合式 API**：`<script setup lang="ts">`；禁 Options API。
- **类型**：接口响应/props 定义类型；跨组件复用放 `types/`；避免 `any`（动态配置渲染等确需处可豁免并注释）。
- **API 调用**：统一 `common/api/http.ts`（自动 token/401 刷新）；禁裸 fetch/axios。
- **路由**：pages 文件自动生成路由，不手写路由表；页面主题（app/admin/standalone）靠目录位置约定。
- **样式**：页面自己的样式写在自己的页面或组件里，优先 UnoCSS 原子类；写入位置决策树与 scoped 白名单见 [前端样式规范.md](前端样式规范.md)，主题色用 CSS 变量（`--note-*` / `--el-*`）；组件库 Element Plus，图表 echarts，三维 babylonjs——新增可视化类库前先确认 template 模块已有能力。
- **权限**：菜单/按钮权限用 `MenuItem.perm` / 权限指令，前端隐藏不代替后端鉴权（后端必须同点位校验）。
- **模块边界**：模块间不互引内部文件；跨模块复用进 `src/common/`。

## 4. 提交与文档

- 提交信息：`feat|fix|refactor|docs|chore: 中文摘要`。
- 功能交付按 [开发流程.md](开发流程.md) 自检清单执行；涉及需求/功能状态变更同步登记册。
- 文档用 Markdown，格式速查见 [markdown.md](markdown.md)；文档导航保持 doc/doc_ch/README.md 与实际文件一致。
