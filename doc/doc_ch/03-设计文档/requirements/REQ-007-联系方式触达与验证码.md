## 3. 方案要点

- 库模式模块：不挂路由、无 HTTP 面，仅暴露 service 与 `get_xxx_service` 依赖注入工厂（同 module_office 先例）
- 通道自动路由：目标为邮箱 → EmailService（SMTP），为大陆手机号 → SmsService（阿里云短信，模板需含 `${code}` 变量）
- 验证码生命周期：60s 发送冷却、5min 有效、校验通过立即失效（一次一用），scene 参数隔离业务场景（register/login…）
- 业务开关留在调用方：注册是否需要验证码仍由 `email.use_for_register`（authorization）把关，module_contact 只管触达与码生命周期
- 动态配置组新增 `sms`（AccessKey/签名/模板 CODE，密钥脱敏），通用配置页即表单
