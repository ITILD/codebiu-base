### 交付明细

**前端 `modules/websearch`（新模块，纯前端，后端零改动）**

- `types/websearch.ts` + `types/index.ts`：与后端 DO 一一对齐——`Engine`(4 值)/`DateRange`(5 值)/`SearchResult`(title/url/description/source/engine/published_date)/`SearchRequest`/`SearchResponse`/`EngineInfo`；不复用 agui.ts 的 `WebSearchResult`（字段语义不同）
- `api/websearch.ts`：`listEngines`(GET /websearch/engines) + `searchWeb`(POST /websearch/search)
- `pages/search.vue`（admin 后台，路由 /websearch/search 自动生成）：InkPageHead + 搜索参数区（关键词回车搜索/引擎下拉/条数 5~30/时间范围不限~一年）+ 结果区（标题外链/摘要/来源·引擎·发布时间 meta 行，列表卡片式 note 主题边框，hover 高亮，el-empty 空态）
- 引擎连通性：`available=false` 的引擎下拉禁用并标"未配置 Key"，页面底部提示可去「数据与配置 → 通用配置 → 网页搜索」补 Key；默认引擎自动选中；搜索失败（400 参数/未配置、502 引擎网络）detail 经 http 层解出 ElMessage 明确提示
- `menu.ts`：后台加"网页搜索"分组（icon Search，perm `websearch:search`，children 搜索测试）——与后端 `websearch:search:read` 权限声明一致，普通用户需管理员授权后可见
