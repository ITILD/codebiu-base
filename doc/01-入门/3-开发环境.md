# 开发环境配置

## 环境列表

| 软件名称 | 用途 | 官网地址 | 说明 |
| -------- | ------------------------- | ------------------------------------------------- | --- |
| vscode | IDE | [vscode](https://code.visualstudio.com/) | 代码编辑器，多语言支持 |
| uv | Python 包和虚拟环境管理器 | [uv](https://github.com/astral-sh/uv) | 替代 pip 和 venv |
| fnm | Node.js 版本管理器 | [fnm](https://github.com/Schniz/fnm) | 比 nvm 更快 |
| pnpm | JavaScript 包管理器 | [pnpm](https://pnpm.io/) | 比 npm / yarn 更快、更省磁盘 |
| flutter | 跨端客户端 SDK | [flutter](https://docs.flutter.dev/get-started/install) | 跨端客户端（code/frontend/flutter） |
| winget | Windows 包管理器 | [winget](https://github.com/microsoft/winget-cli) | Windows 官方包管理器 |

## 注意事项

Windows 需确认已安装 PowerShell 且权限设置正确，以管理员身份打开 PowerShell 执行：
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 1. python 环境配置

### 1.1 安装 uv
```sh
# linux/macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
# win
winget install --id=astral-sh.uv  -e
# win 无 winget
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 1.2 常用命令
```sh
uv -V # 查看版本
uv init # 创建新 Python 项目（含 pyproject.toml）
uv add # 为项目添加依赖
uv remove # 从项目移除依赖
uv sync # 已有项目安装 python 环境和依赖
# 无法连接远程下载源时：
# uv add 你要下的的包 --default-index https://pypi.tuna.tsinghua.edu.cn/simple
```

## 2. nodejs 环境配置

### 2.1 配置 fnm nodejs pnpm
```sh
# linux/macOS 安装 fnm
curl -fsSL https://fnm.vercel.app/install | bash
# win
winget install Schniz.fnm
# win 无 winget：https://github.com/Schniz/fnm/releases 下载压缩包 → 解压 → 配置环境变量
```

fnm 生效（PowerShell 配置文件）：
```sh
if (-not (Test-Path $profile)) { New-Item $profile -Force }   # 创建配置文件
Invoke-Item $profile                                          # 打开配置文件
# 末尾添加：
fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression
```

fnm 常用命令：
```sh
fnm -V # 查看版本
fnm list # 查看本地已安装 Node.js 版本
fnm list-remote # 查看全部可安装的版本
fnm install v22.19.0 # 安装 Node.js稳定版本
fnm use v22.19.0 # 使用稳定版本
fnm default v22.19.0 # 默认版本切换
fnm uninstall v22.19.0 # 卸载
```

安装 pnpm：
```sh
node -v   # 先确认 node 环境（fnm install v22.19.0）
# 使用 corepack（nodejs 包管理器）
# 固定 pnpm 10：pnpm 12+ 改为原生二进制分发，Node v22 自带的 corepack 0.34 不兼容（报 Cannot find module .../bin/pnpm.cjs）
corepack prepare pnpm@10 --activate
corepack enable   # 使 corepack 生效
```

### 2.2 常用命令
```sh
pnpm install # 安装依赖
pnpm run dev # 启动项目
```

## 5. PostgreSQL、Navicat 与数据存储

按需安装 PostgreSQL / Navicat；项目默认可用 SQLite 起步，不装数据库也能跑通基线。

- 本地零依赖：SQLite + Fakeredis（+ LanceDB 可选），无需外部服务。
- PostgreSQL / Redis / Milvus 安装与连接：见 [配置与数据库初始化](../../deveops/运维手册/配置与数据库初始化.md)。
- 配置键、首启建表、管理员种子：见 [后端 03-配置与初始化](../../code/backend/server_py/doc/dev/03-配置与初始化.md)。
- 表结构升级：见 [后端 04-数据库迁移](../../code/backend/server_py/doc/dev/04-数据库迁移.md)。
