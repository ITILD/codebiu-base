## 课程内容

入职第一天任务：「项目代码拉下来启动看一下，自己试着加一个小功能。」

**具体内容**

1. 部署基础环境：vscode、PostgreSQL、navicat、git、uv（Python 版本与依赖库管理器）
2. git 拉取 http://zwork1.w1.luyouxia.net/gitea/codebiu_2025 上的基础文档库和基础后端代码库
3. 在基础后端代码库执行 `uv sync` 安装 Python 依赖
4. 在 `server_py` 目录准备 `config.dev.yaml`（或把 `config.local_file` 置空），启动调试服务，访问 `http://127.0.0.1:6666/docs` 查看模板代码
5. 在 src 下新建 `module_ai` 模块，参考 template 内容实现增加数据功能，最后在 `app.py` 中引用

**必备代码基础**：① 面向对象（类的定义、类与对象的关系）；② Python 程序格式（缩进、行注释、段注释）；③ 模块导入（`import` 与 `from ... import` 的区别）。

**必备知识点**：vscode 基础操作；FastAPI 框架；调试报错与定位能力；代码规范。

**课后任务**：① 重新建文件夹，拉取代码、安装依赖并启动程序；② 根据模板模块新建 `module_ai`，补全其余增删改查。
