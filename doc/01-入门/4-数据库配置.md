## 快速记忆

- **关系库**：`db_rel` 是引导配置，始终读 yaml；PostgreSQL 需先手工建库，应用只建表。**缓存 / 向量库 / 文件存储**：首启以 yaml 为种子入库，之后以「系统管理 → 通用配置」页为准。
- **建表**：全新库首启 `create_all` + 自动 `alembic stamp head`；启动不自动升级。**升级**：发布时显式 `uv run alembic upgrade head`，生产用 `state.check_db=false`。
