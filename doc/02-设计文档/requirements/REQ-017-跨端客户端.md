## 3. 方案要点

- 模块结构：`lib/modules/<模块>/{api,types,providers,pages}` 与 `vue3/src/modules/*` 及后端 `src/module_*` 同名对应（`authorization`/`ai`/`agent`/`rag`/`main`）；跨模块基础设施放 `lib/common/`（组合根 AppCore、主题、设置、拦截器、错误中文化）
- 分层：模块内 `pages → providers → api → types` 四层单向依赖，AppCore 服务定位器持有 Dio 并装配各模块 api
- 接口：复用 `/authorization/auth/*`（登录表单编码、注册 JSON、refresh 不轮换、logout 吊销三件套）、`/ai/llm/chat`（SSE legacy 协议）、`/ai/model-configs/list`
- 跨端：Linux/Windows/macOS 桌面窗口 420×880；Android 明文传输 + INTERNET；iOS ATS 放行局域网 HTTP
- 主题：深翡翠主色 + 明暗双模式，与 Web 端视觉基调一致
