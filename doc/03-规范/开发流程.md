# 开发流程（新功能开发手册）

> 前置：功能已在 [00-需求功能登记册.md](../02-设计文档/00-需求功能登记册.md) 置为「已批准」（见 [需求与功能管理.md](需求与功能管理.md)）。代码风格见 [代码规范.md](代码规范.md)，权限细节见 [后端权限接入FAQ](../../code/backend/server_py/doc/dev/06-权限接入FAQ.md)。

## Step 1 设计确认

- 对照需求卡确认：数据模型 / 接口 / 页面 / 复用设施，有出入先更新需求卡再动手。
- 复用优先级：模型配置(module_ai) > 任务队列(module_task) > 权限/动态配置 > 文件系统(module_file) > 新造轮子。

## Step 2 后端开发

### 2.1 模块结构（垂直切分，五件套齐全）

每个业务线模块必须具备完整的 controller / service / dao / do / dependencies（config/tasks 可选），非业务算法放模块 `utils/`：

- `controller/`：路由端点，仅参数校验 + 调 service，不写业务。
- `service/`：业务逻辑唯一写业务处，controller/任务共享；复杂跨模块业务经模块对外入口调用其他 service，不挖对方内部文件。
- `dao/`：数据访问（关系库 SQLModel 查询 / 向量库操作）；`do/`：SQLModel 表模型 + Pydantic 请求响应体。
- `dependencies/`：FastAPI 依赖注入（分页/鉴权/重依赖惰性加载）；`utils/`：非业务算法与纯工具（无业务状态）；`config/`：permissions.py 权限声明 + server.py 模块初始化；`tasks/`：异步任务。

### 2.2 接入清单

1. **路由注册**：`src/app.py` import 区加 controller import（模块 Router 自动挂载，见文件头注释）。
2. **权限声明**：`config/permissions.py` 声明 `域:资源:动作` 权限点；module_main 管理域节点归 module_authorization 声明；启动自动同步 Casbin。
3. **数据表**：SQLModel 模型加 `table=True`；开发库/全新库由启动 `create_all` 建缺失表，但**必须同时生成 Alembic 增量脚本**，否则生产 `state.check_db=false` 时无法升级（见 [后端 04-数据库迁移](../../code/backend/server_py/doc/dev/04-数据库迁移.md)）。
4. **动态配置**（可选）：业务可热更配置加到 `common/config/dynamic/schemas.py`（schema 即表单，前端零改动）。
5. **向量表**（可选）：继承 `VectorModel`（`table=True`），自动进注册表，启动时 `create_all` 自动发现远端未创建的集合并建表（幂等跳过已存在）；Milvus 的 **str 字段必须声明 max_length**（`Field(json_schema_extra={"max_length": N})` 或 MaxLen 元数据）。向量后端按动态配置 `db_vector.type` 路由（milvus 远程主用 / lancedb 本地备选，SDK 按需安装）。
6. **异步任务**（可选）：tasks 目录写任务函数，在 `module_task/tasks/__init__.py` 的 TASK 注册表登记，双引擎（local/celery）自动生效。
7. **验证**：`uv sync` → `python -c "import sys; sys.path.insert(0,'src'); import app"` → 启动 `python src/app.py` 看启动日志无 error → `/docs` 手测新端点。

## Step 3 前端开发

### 3.1 模块结构（页面/组件/API/类型聚合）

`src/modules/<模块>/`：`api/`（接口封装，用 `common/api/http.ts`，勿裸写 fetch）、`components/`（模块内组件）、`pages/`（页面，自动生成路由）、`types/`（类型定义）。

### 3.2 接入清单

1. **路由**：`pages/<p>.vue` 自动生成 `/<模块>/<p>`，无需手写；页面主题由 `vite.config.ts` extendRoute 约定（app 主应用 / admin 后台 / standalone 独立页）。
2. **菜单**：`src/app/config/menu.ts` 加菜单项（`perm` 与后端权限点一致；首页入口加 `home: true`）。
3. **API**：统一走 `common/api/http.ts`（token 注入/401 刷新重试）；流式走 `aguiStream.ts`（AG-UI 协议）。
4. **样式**：UnoCSS 原子类 + 主题 CSS 变量（`--note-*`），遵循 [响应式规范](../../code/frontend/vue3/doc/dev/04-响应式规范.md)；组件参考 modules/template（element-plus / echarts / babylonjs）。
5. **验证**：`pnpm dev` 手测 → `pnpm run build`（含 type-check）通过。

## Step 4 联调与交付

- 后端 + 前端联调，逐条过需求卡「验收标准」。
- 有数据变更补升级步骤；新依赖确认 `pyproject.toml` / `package.json` 已声明。
- 更新登记册（状态 → 已交付，勾验收标准）与需求卡交付记录；发版同步前端 `versions.ts`。
