# 环境准备
生产/测试服务器的最低环境清单与初始化步骤。

## 1. 基础要求
| 项 | 最低要求 | 说明 |
| :--- | :--- | :--- |
| 系统 | Linux x64(推荐 Ubuntu 22.04 / Debian 12) | Windows Server 可用但脚本需 PowerShell 化 |
| CPU / 内存 | 2C4G(小规模) / 4C8G(含向量检索) | 知识库场景建议 4C8G 起 |
| 磁盘 | 40G+ | 数据库与文件存储单独挂盘更佳 |
| 端口 | 3002(前端)、3001(后端 API)、20001/20002/20005/20006(依赖,仅内网) | 依赖端口与后端端口 **不要**暴露公网 |

## 2. 安装 Docker 与 Compose 插件
```bash
# Ubuntu/Debian 官方脚本安装
curl -fsSL https://get.docker.com | bash

# 验证
docker --version
docker compose version

# (国内服务器)配置镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": ["https://docker.m.daocloud.io"]
}
EOF
sudo systemctl restart docker
```

## 3. 依赖服务(容器方式,推荐)

直接用 `1-依赖环境` 那套，一条命令起齐 PostgreSQL / Redis / Milvus / RustFS：

```bash
cd deveops/运维脚本/1-依赖环境
./ctl.sh up
./ctl.sh status
```

默认端口 `20001/20002/20005/20006`；数据落在同目录 `data/`。
不走 compose、只单独起 PostgreSQL 时：

```bash
docker run -d --name pg \
  -e POSTGRES_DB=codebiu_base \
  -e POSTGRES_USER=here \
  -e POSTGRES_PASSWORD=<强密码> \
  -p 20001:5432 \
  -v $HOME/pgdata:/var/lib/postgresql/data \
  --restart unless-stopped \
  postgres:17
```

## 4. 时区与系统参数
```bash
# 时区(容器内已在 compose 声明 TZ=Asia/Shanghai)
timedatectl set-timezone Asia/Shanghai

# 文件句柄数(大文件上传场景)
echo "fs.file-max = 65535" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

## 5. 应用配置文件
后端运行依赖 `config.yaml`(基线)与覆盖层 `config.dev.yaml` / `config.prod.yaml`：

```yaml
# 关键项示例
server:
  host: 0.0.0.0
  port: 6666                   # 容器内监听端口；宿主机端口由 SERVER_PORT 映射
db_rel:                         # 引导配置，始终以 yaml 为准
  host: 47.94.107.62            # 依赖主机 IP（单机全量时用 127.0.0.1）
  port: 20001
  user: here
  password: <强密码>
  database: codebiu_base
```

```yaml
# 覆盖层 config.prod.yaml(不入 git)
db_rel:
  host: 47.94.107.62            # 依赖主机 IP
  password: <强密码>
file_system:
  max_size: 100                # 单文件上限(MB); S3 连接信息首次启动后在通用配置页配置
```

> 配置键以 `code/backend/server_py/config.yaml` 为准；`db_rel/server/dir/mineru` 为引导配置，其余业务组首启入 `sys_config` 后以通用配置页为准。

## 6. 防火墙建议
| 端口 | 暴露范围 |
| :--- | :--- |
| 3002 | 公网(前端入口) |
| 3001 | 仅内网(后端 API；容器内实际监听 6666) |
| 20001/20002/20005/20006/20007 | 仅内网(PostgreSQL/Redis/Milvus/RustFS) |
