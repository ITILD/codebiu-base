# 环境准备
生产/测试服务器的最低环境清单与初始化步骤。

## 1. 基础要求
| 项 | 最低要求 | 说明 |
| :--- | :--- | :--- |
| 系统 | Linux x64(推荐 Ubuntu 22.04 / Debian 12) | Windows Server 可用但脚本需 PowerShell 化 |
| CPU / 内存 | 2C4G(小规模) / 4C8G(含向量检索) | 知识库场景建议 4C8G 起 |
| 磁盘 | 40G+ | 数据库与文件存储单独挂盘更佳 |
| 端口 | 80/443(对外)、3001(后端默认映射，可用 `SERVER_PORT` 改)、15432(数据库,仅内网) | 15432 / 后端端口 **不要**暴露公网 |

## 2. 安装 Docker 与 Compose 插件
```bash
# Ubuntu/Debian 官方脚本安装
curl -fsSL https://get.docker.com | bash

# 验证
docker --version
docker compose version

# (国内服务器)配置镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": ["https://docker.m.daocloud.io"]
}
EOF
sudo systemctl restart docker
```

## 3. 数据库(容器方式,推荐)
部署编排已内置 `postgres:17`（`profile=pg`，默认不启动；需要 PostGIS/pgvector 时换 `postgis/postgis:17-3.5` 镜像）。不走 compose 时独立启动：

```bash
docker run -d --name pg \
  -e POSTGRES_DB=codebiu \
  -e POSTGRES_USER=codebiu \
  -e POSTGRES_PASSWORD=<强密码> \
  -p 15432:5432 \
  -v $HOME/pgdata:/var/lib/postgresql/data \
  --restart unless-stopped \
  postgres:17
```

## 4. 时区与系统参数
```bash
# 时区(容器内已在 compose 声明 TZ=Asia/Shanghai)
timedatectl set-timezone Asia/Shanghai

# 文件句柄数(大文件上传场景)
echo "fs.file-max = 65535" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

## 5. 应用配置文件
后端运行依赖 `config.yaml`(基线)与覆盖层 `config.dev.yaml` / `config.prod.yaml`：

```yaml
# 关键项示例
server:
  host: 0.0.0.0
  port: 6666                   # 容器内监听端口；宿主机端口由 SERVER_PORT 映射
db_rel:                         # 引导配置，始终以 yaml 为准
  host: postgres                 # compose 网络内用服务名
  port: 5432
  user: codebiu
  password: <强密码>
  database: codebiu
```

```yaml
# 覆盖层 config.prod.yaml(不入 git)
db_rel:
  host: postgres
  password: <强密码>
file_system:
  max_size: 100                # 单文件上限(MB); S3 连接信息首次启动后在通用配置页配置
```

> 配置键以 `code/backend/server_py/config.yaml` 为准；`db_rel/server/dir/mineru` 为引导配置，其余业务组首启入 `sys_config` 后以通用配置页为准。

## 6. 防火墙建议
| 端口 | 暴露范围 |
| :--- | :--- |
| 80/443 | 公网 |
| 3001 | 仅内网(由 nginx 反代；容器内实际监听 6666) |
| 15432/6379 | 仅内网 |
