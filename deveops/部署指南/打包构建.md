# 打包构建

构建入口只有三个脚本，全部在 `deveops/运维脚本/`：

| 脚本 | 产物 |
| :--- | :--- |
| `2-主服务/build.sh` | 后端镜像 + 前端 dist + 完整部署目录 |
| `3-任务队列/build.sh` | 独立 task 镜像 + 任务部署目录 |
| `4-客户端/build_*.sh` | APK / AppImage |

## 1. 后端镜像

Dockerfile 仍放在代码目录，由脚本调用，不重复维护：

| 文件 | 用途 |
| :--- | :--- |
| `code/backend/server_py/tools/docker_dev/Dockerfile.dev` | 主服务镜像（uv 虚拟环境，源码外挂） |
| `code/backend/server_py/tools/docker_task/Dockerfile.task` | 任务队列镜像（同依赖，入口 `src/app_task.py`） |
| `code/backend/server_py/tools/docker_build/Dockerfile.dist` | Nuitka 闭源交付镜像（可选） |

镜像 tag 自动取 `pyproject.toml` 的 `name:version`；任务镜像自动加 `-task` 后缀。

```bash
# 主服务镜像
cd deveops/运维脚本/2-主服务 && ./build.sh

# 任务镜像
cd deveops/运维脚本/3-任务队列 && ./build.sh

# 只更新代码（不重建镜像）
./update.sh
```

可选环境变量：

```bash
SKIP_SERVER=1 ./build.sh   # 只构建前端/同步代码
SKIP_WEB=1 ./build.sh      # 只构建后端
SKIP_BUILD=1 ./build.sh    # 任务队列：跳过镜像（已 docker load 时）
```

## 2. 前端

`2-主服务/build.sh` 用容器内 Node 构建，无需本机装 pnpm：

```
code/frontend/vue3/tools/docker_dev/Dockerfile.dev  ->  dist/  ->  $DEPLOY_DIR/nginx/html/index/
```

构建失败不会覆盖线上旧产物；成功后旧目录自动备份为 `index_时间戳`。

## 3. 客户端

```bash
cd deveops/运维脚本/4-客户端
./build_android.sh       # FAT=1 全架构 / DEBUG=1 debug 包
./build_desktop.sh       # SKIP_APPIMAGE=1 只出 tar.gz
```

产物统一在 `4-客户端/dist/`。

## 4. 版本号约定

| 位置 | 说明 |
| :--- | :--- |
| `pyproject.toml` | 后端版本 = 镜像 tag |
| `package.json` | 前端版本 |
| `doc/tag_doc/tag_x.x.x.md` | 每个版本一份变更记录 |
