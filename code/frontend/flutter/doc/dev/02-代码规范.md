# 02-代码规范（flutter 客户端）

> 通用规范（提交、文档、版本）见根 [代码规范](../../../../../doc/03-规范/代码规范.md)；本文只约束 Flutter/Dart。强制基线：`flutter analyze` 0 issue（含 info）。

## 1. 命名与文件

| 对象 | 规则 | 示例 |
| :--- | :--- | :--- |
| 文件 | `snake_case.dart`；页面 `_page.dart`、服务 `_service.dart`、模型单数名词 | `login_page.dart`、`auth_service.dart`、`user.dart` |
| 类/枚举 | `UpperCamelCase`；页面类与文件同名 | `class ChatProvider` |
| 变量/方法 | `lowerCamelCase`；私有成员 `_` 前缀 | `_replyOnline()` |
| 常量 | `lowerCamelCase`，集中放 `core/constants.dart` 或类内 `static const` | `defaultBaseUrl` |
| 布尔 | `is/has/can/should` 前缀 | `isLocal`、`canRefresh` |

## 2. 硬规则（违反即打回）

1. **分层不越界**：`ui/` 不 import `dio`、不碰 `SharedPreferences`；`providers/` 不 import `widget` 相关库（`material.dart` 禁止出现在 providers/）；`core/` 不 import `providers/`、`ui/`。依赖方向永远 `ui → providers → services → models`。
2. **页面无业务**：页面只做「取状态 → 渲染 → 调 provider 方法 → 展示结果」；数据加工放 provider，HTTP 放 service。
3. **状态管理只用 provider**：跨页共享状态 = ChangeNotifier + `context.watch`（重建）/ `context.read`（回调内取）；禁止页面里再引 rxdart/bloc 等新状态库。
4. **HTTP 只走 `core/services/`**：统一经 `AppCore.dio`（拦截器自动带 token、刷新、错误中文化）；禁止页面/Provider 自建 `Dio()` 或 `HttpClient`。例外：设置页「测试连接」用临时 Dio 探测**新地址**。
5. **模型必带 fromJson/toJson**：字段可空性如实标注；未知字段忽略；解析失败不抛异常到 UI。
6. **错误必须中文化**：用户可见错误一律 `apiErrorMessage(e)` 或 `core.errText(e)`；禁止把 `DioException.toString()` 直接给用户。
7. **异步与 BuildContext**：`await` 之后用 `mounted` 守卫再 `setState`/`SnackBar`/`pop`；`initState` 里做请求放 `addPostFrameCallback`。
8. **控制器必释放**：`TextEditingController`/`ScrollController`/`AnimationController` 在 `dispose()` 释放。
9. **主题色不写死**：颜色一律 `Theme.of(context).colorScheme.xxx`；确需常量色只有 `theme.dart` 的 `seedColor`；深浅两套主题下都要可读。
10. **尺寸壳全局负责**：页面不写 maxWidth 逻辑，宽屏交给 `PhoneShell`；单组件内容限宽（如聊天气泡 320）除外。
11. **平台代码三处同步**：桌面窗口尺寸、应用名等改动必须 Linux/Windows/macOS 同步（见开发指南 5.3）。
12. **依赖克制**：新增第三方包先在 README_AI 登记理由；当前白名单：`dio`、`provider`、`shared_preferences`、`flutter_localizations`。

## 3. Widget 与样式约定

1. **中文文案即界面**：按钮/提示/校验信息全部中文，数字单位半角；按钮文案双字以上空格分隔（`登 录`）沿用现状。
2. **间距节奏**：块内 14、块间 14~18、页边 14~24；圆角：输入框/按钮 10、卡片 12、气泡 14（一角 4 制造方向感）、标签 5~6。
3. **字号阶梯**：正文 14、列表标题 13.5~14、辅助 11.5~12.5、页标题 17（AppBar titleTextStyle）；重要文字 `FontWeight.w600~w700`。
4. **图标**：`Icons.*_rounded`/`_outlined` 系列，尺寸 14~20，与文字基线对齐（Row 里 `crossAxisAlignment` 显式声明）。
5. **加载态**：按钮内 `SizedBox(w:18,h:18, CircularProgressIndicator(strokeWidth:2))`；整页居中 2.4。
6. **空态**：图标 + 一句主文案 + 一句辅助文案 + 动作入口，参考 `model_picker_page.dart`。
7. **表单**：`TextFormField` + `InputDecorationTheme` 全局风格，`prefixIcon` 点缀，`helperText` 只在易错字段加；校验消息中文短句。
8. **Snackbar**：`hideCurrentSnackBar()` 后再 `showSnackBar`，避免堆积。

## 4. Dart 语言用法

```dart
// ✅ 现代语法（强制）
final list = <ModelConfig>[];
String? name;
final label = displayName?.trim() ?? model;   // null 安全链
if (v is Map<String, dynamic>) ...            // 精确类型判断
'nickname': ?nickname,                         // null-aware 集合元素（省 if 判空）

// ❌ 禁止
dynamic x;                                     // 一律具体类型（解析边界 jsonDecode 返回值除外，需立即 cast）
Map<String, Object?> m = ...;                  // 能确定可空性就标注
new Widget();                                  // 不写 new
print();                                       // 用 flutter run 日志或删掉
// ignore_for_file:                            // 禁整文件压制 lint；单行 ignore 需注释原因
```

## 5. 测试要求

1. **纯逻辑必测**：`local_assistant.dart`、模型 `fromJson`、解析器类必须有单测（参考 `test/app_test.dart`）。
2. **Service 不 mock 出网络真话**：涉及后端的用真环境联调验证（开发指南 2.2），测试不依赖外网。
3. **提交门槛**：`flutter analyze`（0 issue）+ `flutter test` 全绿；改平台代码加 `flutter build linux --release`。

## 6. Git 提交（与根规范一致）

- 格式 `feat|fix|docs|refactor|test|chore(client): 摘要`，例：`feat(client): AI 助手支持模型切换`。
- 一次提交一个意图；`pubspec.lock` 随依赖变更一起提交。
