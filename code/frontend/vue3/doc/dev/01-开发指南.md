# 前端开发指南（vue3）

> 技术栈：Vue 3.5 + TypeScript + Vite(rolldown) + Element Plus + UnoCSS + Pinia + unplugin 全家桶。视觉主题见 [02-视觉主题规范](02-视觉主题规范.md)，样式边界见 [03-样式写入规范](03-样式写入规范.md)，断点见 [04-响应式规范](04-响应式规范.md)，菜单权限见 [05-权限与菜单](05-权限与菜单.md)。

## 1. 启动与配置

```bash
cd code/frontend/vue3
pnpm i
pnpm run dev        # 默认 http://localhost:8888（.env 的 VITE_PORT）
pnpm vitest run     # 单元测试
pnpm run build      # vue-tsc 类型检查 + 生产构建
```

| 配置来源 | 内容 |
| :--- | :--- |
| `.env` / `.env.development` | `VITE_PORT`、`VITE_API_PREFIX`、`VITE_PROXY`、`BASE_URL` |
| `vite.config.ts` | 自动路由、自动导入、UnoCSS、分包、版本注入、预览器资产裁剪 |
| `tools/vite/proxy.ts` | 开发代理（`/base_server` → 后端） |

单测 `pnpm vitest run`（用例 `src/**/*.spec.ts`）；构建 `pnpm run build`（`vue-tsc --build` + Vite）；`package.json` 的 `version` 注入 `__APP_VERSION__` 并生成 `dist/version.json`，前端据此轮询新版本。

## 2. 目录结构

分层：

- `src/common`：跨业务公共层。`api/`（`http.ts`/`authFetch.ts`/`httpError.ts`/`aguiStream.ts`）、`components/`（自动全局注册）、`composables/`（`useTableQuery`/`useCrudDialog`/`usePermission`/`useResponsive`）、`enums/`、`i18n/`、`stores/`、`types/`、`utils/`。
- `src/app`：应用壳。`components/layout/`（`SysHeader`/`SysSidebar`/`SysFooter`/`AssistantFloat`）、`composables/useMenu`、`config/menu.ts`/`versions.ts`。
- `src/modules/<模块>`：业务模块。`api/` `components/` `pages/` `types/`，自动路由 `/<模块>/<页面>`。
- `src/pages`：全局页 `index/admin/setting/version/404`。

完整目录树见 [README.md](../../README.md)、[base_web.md](../../base_web.md)。

**边界**：`common/` 只放与业务无关的能力，跨模块复用再下沉；`app/` 只放应用壳与全局配置；模块组件不注册全局，删除模块文件夹应能删除整个功能。

## 3. 自动路由约定

`unplugin-vue-router` 从两处生成路由：

| 来源 | 生成规则 | 示例 |
| :--- | :--- | :--- |
| `src/pages` | 文件路径即路由 | `pages/admin.vue` → `/admin` |
| `src/modules/*/pages/**/*` | `/<模块>/<页面>` | `modules/authorization/pages/user.vue` → `/authorization/user` |

`vite.config.ts` 的 `extendRoute` 统一加 meta：除首页与 404 外全部 `admin: true`（需登录 + 后台侧边栏）；`setting.vue`、`version.vue` 额外 `standalone: true`（需登录，页面自带导航、不渲染侧边栏）；首页入口卡以 `?bare=1` 进入单页模式（不渲染侧边栏）。

入口 `.vue` 不可改名/移位；页面拆分只新增同模块 `components/` 文件。

## 4. 请求层

| 场景 | 使用 |
| :--- | :--- |
| 普通 JSON | `import { http } from '@/common/api/http'` |
| 流式 / Blob / 需要原生 fetch | `authFetch`（自动带令牌） |
| FastAPI 错误解析 | `httpError.ts` 的 `parseFastApiDetail` |
| AG-UI 流式事件 | `aguiStream.ts` |
| 未登录提示 | `http.ts` 已统一提示并广播登录事件 |

- API 文件放模块 `api/`，函数返回**已解包的数据**，不泄漏 Axios/Fetch 细节；查询参数统一传对象，由 `http.ts` 序列化；401 刷新由 `http.ts` 单飞处理，页面不写重试逻辑；上传/下载/预览等 Blob 场景用 `authFetch`。

## 5. 列表页与对话框范式

### 列表页

```ts
import { useTableQuery } from '@/common/composables/useTableQuery'
import { listUsers } from '../api/user'

const { pagination, queryParams, tableData, total, loading, fetchData, handleSearch, refreshAfterRemove } =
  useTableQuery(listUsers, {
    defaultQuery: { username: '', is_active: undefined },
  })
```

- 返回的 `ref` 不要解构后丢失响应性（模板里直接 `pagination.page`）；删除后调用 `refreshAfterRemove()`，自动处理末页回退；查询区用 `TableSearchBar`，表格优先 `ProTable`（列设置/密度/批量/手机卡片已内置）。

### 新增/编辑对话框

```ts
const crud = useCrudDialog({
  formBase: () => ({ username: '', is_active: true }),
  submit: async (form, editingId) => {
    editingId ? await updateUser(editingId, form) : await createUser(form)
  },
  onSaved: fetchData,
})
```

- 对话框拆到同模块 `components/XxxDialog.vue`；子组件 `defineExpose({ open })`，`open` 时重置表单；`props/emits` 必须带类型；复杂表单的详情加载放在 `openEdit` 的 `fill` 回调里。

## 6. 常用公共能力

表格 `src/common/components/pro-table/`、搜索栏（自动注册）、`AppErrorBoundary.vue` / `RouteSkeleton.vue`、日期 `src/common/utils/datetime.ts`（`formatDate/formatDateTime/formatTimeShort`）、权限 `usePermission.ts`、断点 `useResponsive.ts`、批量删除 `useBatchDelete.ts`、语音 `useVoiceInput.ts`、文件预览 `src/modules/file/components/FilePreviewDialog.vue`（完整入口速查见 [doc/README](../README.md)）。**禁止**在页面里重复实现以上能力。

## 7. 常见坑

| 现象 | 原因 / 处理 |
| :--- | :--- |
| 页面 404 | 文件不在 `pages/` 或模块 `pages/` 下；检查自动路由路径 |
| 列表删除后空页 | 用 `refreshAfterRemove`，不要手写页码回退 |
| 样式在暗色下不可读 | 颜色是否走了 `--note-*` 变量；是否只写了亮色值 |
| 移动端横向滚动 | 检查固定宽度/`min-w`，按 [04-响应式规范](04-响应式规范.md) 按移动优先改 |
