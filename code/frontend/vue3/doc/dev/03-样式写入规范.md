# 前端样式规范

> 适用范围：`code/frontend/vue3`。核心原则：页面样式写在页面/组件里，优先 UnoCSS 原子类；全局只保留 `base.css` 主题变量与 `uno.config.ts` 跨页快捷类。断点/字号/按钮/边框细节见 [04-响应式规范.md](04-响应式规范.md)。

## 1. 样式写入位置决策树

按顺序判断，**命中即停，不得越级**：

| 顺序 | 判断 | 写法 |
| :--- | :--- | :--- |
| ① 默认 | 单处使用 | 模板内 UnoCSS 原子类（含 attributify），如 `class="flex items-center gap-2"` 或 `<div mb-4>` |
| ② 页内复用 | 同一组合在本页/组件出现 ≥3 处 | `<script setup>` 定义**类名常量**，模板 `:class` 引用（见 §4） |
| ③ 跨页复用 | 两个及以上页面/模块使用同一组合 | 先查 `uno.config.ts` 的 `shortcuts`/`rules`，没有则新增（中文注释说明用途） |
| ④ 无法原子化 | 命中 §2 白名单场景 | 页面/组件 `<style scoped>`，写在**自己文件**里 |
| ⑤ 主题色 | 新增全局色值 | 先在 `base.css` 建变量，再到 `uno.config.ts` 注册色/快捷类（唯一路径） |

- **样式跟随组件走**：页面/组件私有样式（含白名单 scoped CSS）一律写在本文件，禁止挪到全局样式、父组件或兄弟页面；scoped 里禁止写原子类能表达的布局属性（flex/grid/间距/字号/圆角），只写白名单场景的核心效果。
- 优先复用既有 shortcut：`flex-center`、`center`、`mini-text-center-between`、`page-shell`、`page-card`、`card-toolbar`、`note-icon-btn`、`h-app`。

## 2. `<style scoped>` 白名单场景

只有以下 4 类允许写 scoped CSS：

| # | 场景 | 原因 | 现有示例 |
| :--- | :--- | :--- | :--- |
| 1 | `:deep()` 穿透第三方组件内部 | 原子类够不到组件库内部 DOM | `config.vue` 的 `:deep(.el-aside)`；`model_config.vue` 的表格行弱化；`db.vue` 的 `:deep(.el-table .row-active)` |
| 2 | 依赖 JS 状态 class 的激活态 | 运行时切换类名，原子类无法表达 | `conversation.vue` 的 `.think-btn.active`（静态部分已原子化） |
| 3 | Vue transition 动画类 | `enter/leave` 类名由 Vue 运行时生成 | `conversation.vue` 的 `.fade-*` |
| 4 | 复杂绘制效果 | mask/filter/clip-path/多级渐变/复杂 keyframes | `index.vue` 的 `.note-etch`（SVG mask）；`decor/`、`garden/` 特效组件 |

- 白名单内布局属性仍用原子类写在模板，scoped 只写核心效果（如激活态只写颜色差异）；场景 3 确需非 scoped `<style>` 时（teleport/slot 元素 scoped 命中不了），类名带组件语义前缀（如 `fade-`）并注释原因；不再命中白名单的旧样式随手迁移为原子类。

## 3. 主题色双轨制

两套并行视觉体系，按页面归属选轨，**禁止写死 hex**：

| 轨道 | 适用页面 | 颜色写法 |
| :--- | :--- | :--- |
| note 笔记风 | toC 主题页（index/template/playground 等） | `--note-*` 变量：`text-note`、`bg-note-card`、`border-note`、`text-note-green`… |
| Element Plus 后台风 | 后台管理页（modules/main、ai、rag 等表格/表单页） | `--el-*` 变量：`text-[var(--el-text-color-secondary)]`、`bg-[var(--el-color-primary-light-9)]`… |

- EP 组件主色已被主题变量覆盖，按钮/标签直接用 `type="primary"` 等，不改内部样式。
- 圆角：note 页用语义刻度 `rounded-note-sm/md/lg`；EP 后台页用标准刻度（如 `rounded-lg` = 8px），不写 `rounded-[13px]`。阴影/过渡优先 `shadow-note`、`note-transition`；EP 页用 `--el-box-shadow-light` 等变量。

## 4. 页内类名常量（决策树 ②）

同一组合页内复用 ≥3 处时，在 `<script setup>` 顶部定常量，模板 `:class` 引用：

```vue
<script setup lang="ts">
// ===== 页面局部样式组合(UnoCSS 原子类, 仅本页使用) =====
/** 概览统计卡: 弹性占满 + 悬浮阴影 */
const statCardCls
  = 'flex-1 min-w-45 flex items-center gap-3.5 px-5 py-4 bg-[var(--el-bg-color)] border border-solid border-[var(--el-border-color-lighter)] rounded-lg transition-shadow duration-200 hover:shadow-[var(--el-box-shadow-light)]'
</script>

<template>
  <div :class="statCardCls">…</div>
</template>
```

- **完整类名字符串**：禁止运行时拼接/插值（UnoCSS 按源码文本提取，拼出来的类不生成 CSS）。
- 一个常量只表达一个语义单元（卡片/图标/标题），不堆整段模板类；常量必须有中文注释说明用途。

## 5. 命名与注释

- scoped 类名用本页语义小写中划线（`stat-card`、`think-btn`），禁止通用名（`.card`/`.title`/`.active` 单独存在）；每个 `<style scoped>` 块开头注释"为何保留 scoped"（对应白名单编号），复杂选择器逐条注释；删除元素/功能时同步删除样式与模板 class，不留死类（如无定义的 `stat-time`）。

## 6. 禁止事项

- ❌ 新增全局生效的样式类（非 scoped `<style>` 定义通用类）——全局能力只经 `uno.config.ts` shortcuts/rules 提供
- ❌ scoped CSS 写布局（display/gap/padding/margin/font-size 等原子类可表达项）
- ❌ 写死 hex 色值、px 写正文字号（见响应式规范 §2.1）
- ❌ 滥用 `!important`（仅覆盖 EP 内联样式时允许，须注释原因）
- ❌ 把页面私有样式提取到"公共样式文件"或父组件（谁用谁持有）

> 提测前自检：优先原子类，页内复用 ≥3 处提类名常量且为完整字符串；scoped 命中白名单且块首有注释；颜色走 `--note-*`/`--el-*`，圆角走语义/标准刻度；无新增全局类、无 `!important`、无 px 字号；删除时清理死类。
