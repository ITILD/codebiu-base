# 权限与菜单（前端）

> 后端权限模型见根 [03-权限设计](../../../../../doc/02-设计文档/03-权限设计.md)；后端接口权限接入见 [server_py/doc/dev/05-权限体系与接入](../../../../backend/server_py/doc/dev/05-权限体系与接入.md)。本文只讲前端：菜单、路由、按钮、首页入口。

## 1. 权限码约定

格式与后端一致：

| 级别 | 格式 | 示例 |
| :--- | :--- | :--- |
| 目录级 | `模块` | `sys`、`rag` |
| 菜单级 | `模块:资源` | `sys:user`、`rag:project` |
| 按钮/接口级 | `模块:资源:动作` | `sys:user:create`、`rag:project:delete` |

- 全局管理员权限为 `["*"]`；`hasPerm('sys:user')` 对"拥有该码"或"拥有任意 `sys:user:*` 子权限"都返回 true；前端权限码必须与后端 `config/permissions.py` 完全一致，否则菜单可见但接口 403。

## 2. 菜单配置：`src/app/config/menu.ts`

唯一数据源，驱动后台侧边栏、面包屑、首页入口卡、头像下拉"后台管理"。末级项字段：

| 字段 | 作用 |
| :--- | :--- |
| `index` | 路由路径，必须与自动生成的路由一致 |
| `title` | 菜单标题 |
| `perm` | 权限码；缺省表示登录即可见 |
| `system` | 系统级配置，侧边栏显示"系统"小标 |
| `home` | 同时出现在首页入口卡，以 `?bare=1` 单页模式进入 |
| `admin: false` | 不进入后台侧边栏（仅首页入口等场景） |
| `icon` / `desc` | 首页入口卡图标与描述 |

- 所有功能页以后台侧边栏「分组 → 末级子项」平铺，页面内不再做页内导航；新增页面在对应分组 `children` 增加一项，需要首页露出时加 `home: true`。
- `adminMenuItems` 自动剔除 `admin: false`；`homeEntries` 自动展平 `home` 末级项；从首页进入用 `homeLink(path)`，自动追加 `?bare=1`。

## 3. 路由与登录拦截

`vite.config.ts` 的 `extendRoute` 统一标记：

| meta | 含义 |
| :--- | :--- |
| `admin: true` | 除首页/404 外全部页面：需登录 + 后台侧边栏 |
| `standalone: true` | `setting.vue`、`version.vue`：需登录，但页面自带布局，不渲染侧边栏 |
| `?bare=1` | 首页入口卡进入的单页模式：不渲染侧边栏，顶栏 Logo 返回首页 |

路由守卫只做登录态拦截；菜单可见性由 `useVisibleMenu` / `useVisibleHome` 按权限过滤，两者职责分开。

## 4. 菜单过滤：`src/app/composables/useMenu.ts`

```ts
const { visibleMenuItems } = useVisibleMenu()   // 后台侧边栏
const { visibleHomeEntries } = useVisibleHome() // 首页入口卡
```

- 目录声明 `perm` 无权限则整组隐藏；子项声明 `perm` 逐项过滤，`admin: false` 不进侧边栏；首页入口未登录时全部展示（点击后引导登录），登录后按权限过滤；页面/组件不要自己遍历 `menuItems`。

## 5. 按钮级权限

```vue
<script setup lang="ts">
const { hasPerm, hasAnyPerm, isAdmin } = usePermission()
</script>

<template>
  <el-button v-if="hasPerm('sys:user:create')" type="primary">新增</el-button>
  <el-button v-if="hasAnyPerm(['sys:user:update', 'sys:user:delete'])">批量操作</el-button>
</template>
```

- 按钮权限只做"是否展示"，后端接口仍须独立鉴权；前端隐藏不是安全边界；不要用 `isAdmin` 硬编码业务分支，优先用具体权限码；行级/数据级权限（如知识库成员档位）由后端返回字段决定（如 `can_edit`），前端不自行推断。

## 6. 新增页面权限清单

1. 页面文件放 `modules/<模块>/pages/` 或 `pages/`，确认自动路由路径；`menu.ts` 加菜单项，`index` 与路由一致并声明 `perm`。
2. 后端 `config/permissions.py` 声明同名权限码，角色/权限配置页给角色分配该权限码；按钮级操作用 `hasPerm` 控制展示。
3. 验证：无权限账号看不到菜单；直接访问 URL 时接口返回 403；有权限账号可正常操作。
