# 响应式自适应规范

> 适用范围：`code/frontend/vue3`（Vue3 + Element Plus + UnoCSS）。新增样式必须复用 `uno.config.ts`、`base.css` 既有约定（`--note-*`、`h-app`、`page-shell`、`note-sm/md/lg` 圆角）。目标：手机/平板/桌面/超宽屏布局合理可读，无横向滚动、文字截断、按钮挤压、热区过小。

## 1. 断点体系

### 1.1 统一断点

以 UnoCSS `presetWind3`（Tailwind v3 语义）为准，只用以下断点，禁止自定义：

| 代号 | 最小宽度 | 典型设备 | 布局定位 |
|------|----------|----------|----------|
| （默认） | 0px | 手机竖屏（<768px） | 单列、抽屉导航、大间距 |
| `sm` | 640px | 手机横屏 / 小平板竖屏 | 单列为主，允许双列卡片 |
| `md` | 768px | 平板竖屏 / 小窗口桌面 | 侧边导航出现，双列布局 |
| `lg` | 1024px | 平板横屏 / 笔记本 | 标准桌面布局 |
| `xl` | 1280px | 桌面 | 内容区限宽 |
| `2xl` | 1536px | 大屏 / 超宽屏 | 内容区限宽居中 |

### 1.2 使用原则

- **移动优先**：先写手机端，再用 `sm:` `md:` `lg:` 向上覆盖（`page-shell` 移动 `p-4`/桌面 `p-6`；`h-app` 移动减 `h-14`/桌面减 `h-16`）。
- **方向一致**：不用 `max-md:` 反向断点做主逻辑（个别微调除外），手机跳桌面用 `md:`，不写 `sm:md:lg:` 三连。
- **关键分界**：`md`（768px）切换手机/桌面（导航形态、列数、弹窗形态）；`lg`（1024px）为内容限宽分界。

## 2. 字体规范

### 2.1 字号阶梯

字号用 `rem`，根字号不锁定；禁止 `px` 写正文字号（图标与 1px 细节除外）。

| 层级 | 手机（<md） | 桌面（≥md） | UnoCSS 写法 | 用途 |
|------|------------|------------|-------------|------|
| Hero 标语 | 28px | 36px | `text-3xl md:text-4xl` | 首页主标语 |
| 页面标题 H1 | 22px | 24px | `text-xl md:text-2xl` | 页面头 |
| 区块标题 H2 | 18px | 20px | `text-lg md:text-xl` | 卡片/面板标题 |
| 小标题 H3 | 16px | 16px | `text-base font-semibold` | 表单分组、列表头 |
| 正文 | 14px | 14px | `text-sm` | 默认正文（与 Element Plus 对齐） |
| 辅助说明 | 12px | 12px | `text-xs text-note-sub` | 提示、占位、时间戳 |
| 手写体点缀 | 按需 | 按需 | `font-hand` | Hero/空状态装饰，不承载信息 |

### 2.2 行高与字重

- 正文 `leading-relaxed`（1.625），标题默认 1.3；中文字重仅 `font-normal` / `font-medium` / `font-semibold`，禁止 `font-bold` 用于中文长文本；数字/代码用 `font-mono`，金额、ID 列加 `text-right`。

### 2.3 文本自适应与截断

- 单行用 `text-ellipsis`（不手写三条属性），多行用 `line-clamp-2` / `line-clamp-3`；页面 H1 允许换行，禁止截断；文本 ≥12px，`text-xs` 不用于主操作按钮文字；用户输入、URL、hash 容器加 `break-all` 或 `break-words`。

## 3. 按钮规范

### 3.1 尺寸分档

用 `size` 属性 + 动态计算切换，不用 CSS 覆盖按钮内部 padding：

```ts
// composables/useResponsive.ts（约定：全局唯一获取断点的入口）
import { useBreakpoints } from '@vueuse/core'

const breakpoints = useBreakpoints({ sm: 640, md: 768, lg: 1024, xl: 1280 })
/** 是否移动端布局（<768px），全站共用 */
export const isMobile = breakpoints.smaller('md')
```

| 场景 | 手机 | 平板/桌面 | 说明 |
|------|------|-----------|------|
| 页面主操作（提交/保存） | `large`（≥40px 高） | `default`（32px） | 主操作在移动端加大，保证触控 |
| 表格行内操作 | `small` | `small` | 两侧不随断点变化 |
| 工具栏图标按钮 | 自定义 `note-icon-btn` | 同左 | 28px 方寸，见 `uno.config.ts` |
| 表单内按钮 | 与表单控件同高 | 同左 | 跟随 el-form 尺寸 |

- 动态取尺寸：`<el-button :size="isMobile ? 'large' : 'default'">`。

### 3.2 布局与排列

- 一个视图内 primary 按钮最多 1 个，其余 default / text；移动端 ≤2 个操作时底部通栏、主按钮在右（`fixed bottom-0 inset-x-0 p-4 flex gap-3 bg-note-card md:static md:p-0`）；操作 >2 个收进 `el-dropdown`，只留主操作 + 更多。
- 按钮组横向间距 `gap-2` 起（不用 margin），两端对齐用 `mini-text-center-between`；中文文字 2~4 字 + `whitespace-nowrap`；异步提交必须 `:loading`，禁用态不加遮罩。

### 3.3 触控热区

- 可点热区 ≥ **44×44px**（含 padding）；小图标按钮须外扩热区（`after:absolute after:-inset-2`），相邻可点元素间距 ≥ 8px。

## 4. 边框规范

### 4.1 基本原则

- 颜色用 `border-note`（淡绿灰）或 `border-note-green`（强调），禁止写死 hex；宽度仅 1px，强调/选中 2px 需预留空间（选中态优先 `bg-note-tint`）。
- 分隔线：卡片内 `note-dashed-divider`，列表项之间 `divide-y divide-note/60`。

### 4.2 无边框优先

用色差和阴影区分层级，不画边线：

| 层级 | 手机/桌面统一做法 |
|------|-------------------|
| 卡片 | `page-card`（无边线纸片 + `shadow-note` 光晕环） |
| 输入框/按钮 | 保留 Element Plus 默认 1px，不改写 |
| 分区 | 背景色差（`bg-note-soft` vs `bg-note-paper`），不画框 |
| 表格 | 去竖线：`<el-table>` 不开 `border`，仅保留行分隔 |

- 圆角只用语义刻度：`rounded-note-sm`（输入框/按钮）、`rounded-note-md`（卡片/表格）、`rounded-note-lg`（对话框/抽屉），禁止 `rounded-[13px]`；移动端卡片无边框靠阴影，桌面描边用 `md:border md:border-note/60`，不再同时叠加阴影变化。
- `-mx-4` 负边距吃 `page-shell` 内边距时必须去圆角：`-mx-4 rounded-none md:mx-0 md:rounded-note-md`。

## 5. 按钮组与操作区

- **工具栏**：`card-toolbar`（`flex flex-wrap items-center justify-between gap-2`），左标题右操作；移动端搜索框 `w-full`，桌面 `sm:w-52`，靠 `flex-wrap` 换行，不写 media query；操作 >3 个时低优先级收进 `el-dropdown`。
- **表格行内**：>2 个操作时移动端只留 1 主操作，其余进 `el-dropdown`
  - 桌面全显（≤3 个）
  - 行内按钮一律 `text` 型 + `small` + 图标 `i-ep-xxx` + tooltip
  - 分页移动端 `layout="prev, pager, next"`，桌面 `layout="total, sizes, prev, pager, next, jumper"`，用 `:layout="isMobile ? ... : ..."` 切换
  - 批量操作栏选中后浮现于表格上方 `card-toolbar`。
- **表单按钮**：弹窗 footer 右对齐 `justify-end gap-2`，移动端全屏（见 §6.3）后按钮底部固定；筛选表单 `inline` + `flex-wrap`，移动端每项 `w-full sm:w-auto`。

## 6. 布局组件自适应

### 6.1 栅格与列数

UnoCSS Grid，间距统一 `gap-4`（16px）：

| 内容类型 | 手机 | sm | md | lg+ |
|----------|------|----|----|-----|
| 卡片列表 | 1 列 | 2 列 | 2~3 列 | 3~4 列 |
| 表单 | 1 列 | 1 列 | 2 列 | 2~3 列 |
| 统计指标 | 1 列 | 2 列 | 3 列 | 4 列 |

### 6.2 导航

- 手机（<md）顶部 `h-14` 吸顶（`bg-note-glass + backdrop-blur-md`），侧边内容进 `el-drawer`；桌面（≥md）顶部 `h-16` + 常驻侧边栏（`w-56 lg:w-64`）；内容区高度统一用 `h-app` / `max-h-app`，禁止各页面自算 `calc`。

### 6.3 弹层

| 组件 | 手机 | 桌面 |
|------|------|------|
| Dialog | 全屏或 `width="92%"`，`top` 减小 | 居中，宽度按内容 480~720px |
| Drawer | 底部抽屉（`direction="btt"`）适合列表选择；表单编辑用全屏 | 右侧抽屉 `size="480px"` |
| Popover/Dropdown | 允许时转 `el-drawer` 或全屏 ActionSheet | 默认 |

- 弹窗用 `:width="isMobile ? '92%' : '640px'"`；内容区 `max-h-app overflow-auto`，footer 不随滚动；移动端禁用 `close-on-click-modal`（误触率高）。

### 6.4 表格

- 横向滚动：外层 `overflow-auto`，固定首列 `fixed="left"` + 操作列 `fixed="right"`；长列用 `min-width` 而非 `width`。
- <md 降级为卡片列表（label:value），`isMobile` v-if 切换，两套结构共用同一数据源。

### 6.5 表单

- Label：桌面 `label-position="right"` + `label-width`，移动端 `label-position="top"`（`:label-width="isMobile ? undefined : '96px'"`）。
- 输入控件移动端 `w-full`，日期范围、级联等宽控件单独换行；校验信息用 Element Plus 默认行为，禁止自定义绝对定位提示。

## 7. 系统与设备适配

### 7.1 安全区（刘海屏/底部手势条）

```css
/* base.css 或页面根容器 */
.page-shell { padding-bottom: calc(1rem + env(safe-area-inset-bottom)); }
/* 底部固定按钮栏 */
.bottom-bar { padding-bottom: calc(1rem + env(safe-area-inset-bottom)); }
```

- `viewport` meta 须包含 `viewport-fit=cover`（检查 `index.html`）。

### 7.2 输入与交互

- 移动端弹窗/表单输入框用 `size="large"`（40px 高，字号 16px），阻止 iOS 聚焦自动放大；现代浏览器已消除 300ms 延迟，无需 fastclick；拖拽交互（VueFlow、画板）触屏必须提供替代操作（长按菜单或按钮），<md 提示"建议使用桌面端获得完整体验"。

### 7.3 横竖屏与键盘

- 手机横屏（`sm` 档）允许 2 列，视频/画布类保持全宽；软键盘弹起时表单页用 `min-h` 而非 `h` 定高，底部固定按钮可监听 `focusin/focusout` 隐藏。

### 7.4 超宽屏与限宽

- 内容主区 `max-w-7xl mx-auto`（1280px），超宽屏两侧留白；全局背景 `bg-note-paper` 铺满，内容卡片限宽居中。

## 8. 图片与媒体

- 图片容器固定宽高比 `aspect-video` / `aspect-square` + `object-cover`，防加载抖动（CLS）；头像 `el-avatar` 固定尺寸，移动端 `size` 缩小一档；大图列表 `loading="lazy"`；图标走 `presetIcons`（`i-ep-*`），尺寸用 `text-base/text-lg`。

## 9. 性能与降级

- 动效统一 `note-transition`（200ms ease-out）；移动端禁用大面积 blur（`backdrop-blur` 仅吸顶导航）；`note-card-hover` 触屏无效但无害。
- 遵循 `prefers-reduced-motion`；重型组件（Monaco 编辑器、ECharts 图表容器等）<md 延迟加载或降级视图，不进首屏。

  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
  }
  ```

- [ ] 热区 ≥ 44×44px 且间距 ≥ 8px；主操作移动端 `large`、桌面 `default`；primary 唯一。
- [ ] 表格移动端可横向滚动（首列+操作列固定）或已降级卡片；弹窗移动端禁用点遮罩关闭，footer 不随滚动。
- [ ] 底部固定元素已加 `env(safe-area-inset-bottom)`；输入框聚焦不被键盘遮挡。
- [ ] 字号未用 px 写死、无 <12px 文本；边框/圆角/颜色全部引用 `--note-*` 与语义刻度；触屏 hover 依赖有替代入口。
